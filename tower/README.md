# NOVA 概念试炼塔 · Concept Tower

> **RPG 练判断，试炼塔练记忆。** 与《AI PRODUCT RPG》同世界观的姐妹游戏。

内置 **153 道 AI 产品/运营校招概念题**（覆盖 ML / DL / NLP / CV / 推荐 / LLM / 推理 / RAG / Agent / 多模态 / 评估 / Infra / 产品 / 运营 / 商业 / 美团业务场景），做成一座 15 层的 roguelite 爬塔：每层一道题，答对通关、答错掉血，错题化作"暗影"反复回塔复仇，直到你真正掌握。

## 🎮 怎么玩

浏览器打开 `index.html` 即可（纯前端、零依赖、离线可玩）。进度自动保存在浏览器本地。

## 🗼 核心机制

| 机制 | 说明 |
|------|------|
| **爬塔遭遇** | 每层一道概念题；3 颗心，答错 -1，血尽局终（roguelite） |
| **⚡ 精英层** | 第 5/10 层限时 25 秒，双倍金币 ×1.5 分数 |
| **☠ BOSS 层** | 顶层是场景级综合题，+300 分 |
| **👁 暗影复仇** | 答错的题不会消失：3 层后回塔再考；**连续两次答对同一暗影才算净化（跨局生效）**——间隔重复记忆法的游戏化 |
| **连击经济** | 连答正确 → 金币加倍；金币在补给站买道具 |
| **道具 = 考试策略** | 50/50 排除、考点提示、复查券（免伤重答）、药水、沙漏 |
| **11 座专项塔** | LLM 训练 / 推理成本 / RAG / Agent / 地基 / 推荐广告 / Infra / 评估 / 产品商业 / 美团模式 / 混合乱斗 |
| **弱点侦察** | 选塔页根据历史正确率推荐你最该刷的模块 |
| **段位系统** | 见习生 → Product Associate → AI PM → Senior → Head of AI Product（生涯积分累计） |
| **概念图鉴** | 作答即收录（错题也收录），按模块统计收录率 |

**键盘**：`A-D` / `1-4` 选答案，`Enter` 下一层。

## 🗂 结构

```
tower/
├── index.html       # 战斗布局 + 终端风样式
└── js/
    ├── deck-data.js # 153 题（含答案/考点/难度/优先级/解析）
    └── game.js      # 爬塔引擎
```

## 🔄 更新题库

题库解析器在仓库根目录 `tools/build-deck.py`（Markdown 题库 → `deck-data.js`）：

```bash
python3 tools/build-deck.py 题库A.md 题库B.md -o tower/js/deck-data.js
```

## 🎯 建议用法（和 RPG 配合）

1. **每日常规**：混合乱斗塔 1-2 局（约 10 分钟）→ 保持手感 + 暗影自动帮你复习错题
2. **发现弱点**：看选塔页"弱点侦察"→ 专攻对应塔
3. **考前冲刺**：P0 模块（LLM/RAG/Agent/评估）专项塔
4. **理解不通时**：去 RPG 玩对应 Case（剧情建立直觉），再回塔里固化记忆
