# 迭代记录 / Changelog

> 产品视角的版本史：每一步都从用户问题出发。工程细节见各文件头部版本号（如 `game.js v34`、`engine.js v17`、`deck-data v8`）。

## v0.4 · 双端与进阶内容（当前）

- **微信小程序端同步上线**：hub / 塔选择 / 答题三页面，与 Web 端共享同一份题库与解锁逻辑（`utils/core.js` 与 `tower/js/game.js` 同源双运行时），兑换码两端互通。
- **每题四选项逐一判定**：不只是"答案+解析"，而是每个选项都有一句判词（为什么对/为什么错），把"蒙对"变成"排除法可教"。小程序同步。
- **进阶实战塔（6 座 · 90 题）**：按各大厂测评风格原创编写（非官方真题），零后端兑换码解锁——题库以密文形式随前端分发，哈希校验与解密全部在本地完成，无需服务器。基础 245 题永远免费。
- **题库加密分发管线**：`tools/pack-paid.py` 打包 + `shared/paid-crypto.js` 纯 JS SHA-256 实现（Web/小程序双端），smoke 测试覆盖"密文不含明文、跨塔码拒绝、真码可解密"。
- **贡献榜 3.0**：你的头像和昵称（本地生成）会出现在榜上——它是"你的"榜单。
- 工程面：161 条 smoke 断言全绿；Service Worker 缓存版本化（nova-v16）；主测试脚本覆盖双端安全边界。

## v0.3 · 仪式感与留存（六爻 · 植物 · 年鉴）

- **🎋 六爻求签（随喜）**：不是随机数——同一个名字+日期+时辰永远摇出同一签。自研确定性派签算法：1080 签池按日期旋转，**数学上保证任意 90 天窗口内一人不重签**；含本卦/之卦/动爻完整六爻规则（京房纳甲简化版）。随喜写进年鉴感谢墙（金色卡片）。
- **伴学植物 3.0 · 跨游戏时间资产**：三盆植物（文竹/风铃草/星语藤）在两个游戏里共享同一份"学习时长账本"——在 RPG 里学的每一分钟，回到试炼塔它也在长；试炼塔左下角常驻小花盆提醒你"它记得你"。
- **📖 年鉴风反馈墙（美高拼贴）**：几何头像生成器（8 种 SVG 头像，不上传任何真实照片）、匿名开关、贴纸感卡片；内置 11 条示范留言（含"报 bug 的正确姿势"）。设计动机：让用户敢说真话。
- **每题解析升级**：从"答案+一句话"升级为四选项逐一判词；题库难度曲线重排（告别"三短一长选最长"）。

## v0.2 · 记忆系统成型（暗影 · 每日挑战 · 成就）

- **暗影复仇 2.0**：错题不再只是列表——它们化为暗影回到塔里等你，连对两次才净化，跨局生效。间隔重复的记忆科学，被包成了"复仇"的叙事。
- **🎴 每日挑战**：全世界今天爬同一座塔（日期做随机种子），1 心 10 层，连胜 streak。
- **🏆 跨游戏成就墙**：18 枚成就，两游戏互通，随存档码打包带走。
- **🗼 塔体系扩容**：11 座基础专项塔 + 6 座大厂风格实战塔，`?mod=` 直达链接，弱点侦察，段位系统。
- **贡献榜**：不给名次只给贡献值（本地），附 9 位示范塔友——避免"榜上无名"的挫败感。
- PWA 离线游玩（Service Worker）、全键盘操作、92 BPM 试炼 BGM（可关）。

## v0.1 · 双世界 MVP

- **AI PRODUCT RPG**：十周试用期剧情（10 个 Case），指标自然下滑机制（不进则退），94 词术语悬浮词典，四档季终结局（100% 首答命中 = 天选之人），开场/每章/终章过场动画，≈50 分钟通关。
- **概念试炼塔**：roguelite 爬塔（3 心 / 限时精英层 / BOSS 层 / 道具商店），每题一句话解析，≈10 分钟一局。
- **两界之桥**：术语表互通（RPG 里点术语 → 直跳塔里对应题）、存档码跨设备、错题本与暗影同法则。
- 零依赖：纯原生 HTML/CSS/JS，无构建、无框架、无后端，GitHub Pages 直接托管。
