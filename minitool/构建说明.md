## 适配改动清单（源 → 小工具版）

**index.html**
- viewport → `maximum-scale=1, user-scalable=no, viewport-fit=cover`；移除 manifest（PWA）
- 移除 logo 的 `onclick` 跳门户（多页跳转禁用）；移除底部 Service Worker 注册内联脚本
- 脚本全部改 `./assets/*.js` 相对引用、去 `?v=` 缓存参数；**移除 tip.js**（求签随喜含个人收款码，站外交易不进容器）
- CSS 兼容层（Chrome 61 基线）：Flex `gap` ×19 → 子项 margin 基线；Grid `gap` ×4 → `grid-gap`；`inset` ×3 → 四边展开；`min(860px,94vw)` → `width+max-width` 回退；`backdrop-filter` 补 `-webkit-` 前缀（rgba 基线已在）；toast/dock 底部安全区用 `var(--safe-area-inset-bottom, env(...))` 组合；补 `touch-action:manipulation`、`-webkit-touch-callout:none`

**game.js**
- 付费墙：移除爱发电外链按钮与 `target="_blank"`（容器禁外链禁新窗）→ 改为文字指引"到网页完整版购买兑换码，回来本地验码解锁"；**离线验码解锁逻辑完整保留**（兑换码制零后端，容器内可用）
- 移除求签入口（DOCK.mount 去掉 onTip；年鉴内 fbTip 按钮移除）
- 3 处生成 HTML 的行内 `gap` 改 margin/块布局；nvPlant CSS 补 `-webkit-backdrop-filter`

**feedback.js**
- 年鉴"复制给制作人"：容器禁剪贴板且禁长按菜单 → 按钮移除，留言纯本地保存（提示文案同步改为离线版语义）
- 注入 CSS 的 7 处 flex `gap` → margin 基线

**dock.js / cinematic.js / achievements.js**
- 注入 CSS 同批兼容改造（gap/inset/grid-gap/backdrop 前缀）；dock 补底部安全区

**未动**：deck-data.js（245 免费题）、deck-paid.js（6 座付费塔密文+码表）、paid-crypto.js、learner.js、leaderboard.js、plant-core.js、bgm.js（WebAudio 手势门控，容器可用）
