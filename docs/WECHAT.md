# 微信小程序版 · 发布指南 / WeChat Mini Program Guide

小程序版已将「概念试炼塔」完整移植为原生小程序（WXML/WXSS/JS，非 web-view 嵌套），位于 `miniprogram/`。AI PRODUCT RPG 小程序版为后续规划（hub 页已预留入口）。

## 一、前置条件（你需要自己完成的 3 件事）

1. **注册小程序账号**（个人主体免费）：[mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 小程序 → 需要未绑定过公众号的邮箱 + 本人微信实名 + 手机号。注册后在「设置 → 基本设置」拿到 **AppID**。
2. **下载微信开发者工具**（稳定版）：[开发者工具下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（macOS / Windows 均可）。
3. **本仓库代码**：`git clone` 或直接下载 ZIP，得到 `miniprogram/` 目录。

## 二、导入并预览（5 分钟）

1. 打开微信开发者工具 → 导入项目 → 目录选择 `miniprogram/`
2. AppID 填你自己的（或先选「测试号」体验，测试号不能发布）
3. 编译后模拟器即可玩；点「预览」生成二维码，**手机扫码真机试玩**
4. 项目自带 `project.config.json`（当前为 `touristappid`，记得替换）

## 三、发布上线

1. 开发者工具右上角「上传」→ 填版本号（如 1.0.0）和备注
2. 登录 mp.weixin.qq.com → 版本管理 → 开发版本 → **提交审核**
3. 审核通过 → 全量发布 → 用户可搜索/分享到你的小程序

### ⚠️ 审核合规要点（重要）

| 事项 | 说明 |
|------|------|
| **类目选择** | 选「**教育 → 在线教育**」或「**工具 → 效率**」。**不要选"游戏"类目**——个人主体不可申请游戏类目，且游戏需要版号 |
| **定位表述** | 介绍文案用「AI 产品经理求职备考**学习工具**/题库练习」，避免"游戏""娱乐"等表述（代码内文案已按此口径） |
| **内容合规** | 题目均为原创教学模拟题，无真实试题盗版；不含医疗/金融等高风险内容 |
| **个人主体限制** | 不能用 web-view 嵌 H5、不能虚拟支付——所以本版本是原生移植，也不涉及内购 |

## 四、题库更新

题库与网页版同源。改题后重新生成两端数据：

```bash
python3 tools/build-deck.py 题库A.md 题库B.md -o tower/js/deck-data.js --mp
```

`--mp` 会同步更新 `miniprogram/data/deck.js`。
